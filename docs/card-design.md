# 卡片视觉设计稿 · 金额主导版

> 目标：**金额是唯一的视觉主角**，其余元素退到背景层。
> 现版本的问题是「元素太多、金额被挤」——标签、¥、状态胶囊、工具栏、底栏各自抢了一点空间。

## 1. 核心原则

1. **一屏只有一个焦点**：金额。其他所有元素的服务目标是「不打扰它」。
2. **金额按宽度撑满**，不是按固定字号。字号 = 由可用宽度反推出来的最大值。
3. **越次要的元素越小、越淡**：标签 11px / 35% 透明度，底栏 12px / 55%。
4. **装饰可以去掉**：`¥` 符号、状态胶囊的圆点、工具栏的边框，都是可选项。

## 2. 版面（推荐方案 A：极简）

```

│  周四 · 11月12日                            工作中  ⚙ ✕ │  36px 页眉
│                                                        │
│                                                        │
│              0 3 5 8 . 2 9 1 7                         │  ← 金额区 ~120px
│                                                        │
│                                                        │
│  ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬                        │  ← 进度条 6px
│  距周末 1天3小时      距下班 03:09:54     本月 9/21     │  ← 底栏 36px
└────────────────────────────────────────────────────────┘
```

关键取舍：

- **去掉「窝囊费已赚」这行标签**，或缩到 10px、30% 透明度，紧贴金额上方（可选开关）。
- **去掉 `¥` 符号**（或缩到金额高度的 40%，贴在左侧基线）。它占宽不参与信息表达。
- **状态胶囊只留文字**，去掉圆点与背景块。
- **工具栏只在悬停时出现**，平时只剩日期行右侧两个小图标（⚙ ✕），置顶用热键。

## 3. 尺寸规范

| 元素 | 字号 | 颜色 | 说明 |
|---|---|---|---|
| 金额·整数 | **按宽度自适应，上限 120px** | 主色（荧光绿 `#4DFF9F` / 深绿 `#04895A`） | 视觉焦点 |
| 金额·小数 | 整数的 **0.5 倍** | 同上，透明度 85% | 与整数共基线 |
| 小数点 | 小数的 0.6 倍 | 同小数 | 不单独占满格 |
| 日期 | 13px | 55% 灰 | 左上 |
| 状态文字 | 12px | 主色 | 右上，无胶囊 |
| 进度条 | 高 6px，圆角 3px | 引线 / 灰烬 | 通栏，左右 20px |
| 底栏标签 | 11px | 35% 灰 | |
| 底栏数值 | 14px | 主文字色 | |

## 4. 金额自适应算法

```
可用宽度 = 卡片宽 − 2 × 20（左右留白）
从 120px 起，每次 −2px：
    整数宽 = 位数 × 单字宽(字号) × 0.92   ← 0.92 是收紧的字距
    小数宽 = 位数 × 单字宽(字号 × 0.5) × 0.92
    总宽 = 整数宽 + 小数点 + 小数宽 (+ ¥宽)
    若 总宽 ≤ 可用宽度 → 采用该字号
```

要点：

- **字距固定收 8%**（`MeasureString` 的实际前进宽度 × 0.92），比调字号更能显大。
- 整数与小数**共用基线**，用 `FontFamily.GetCellAscent()` 算真实基线。
- 金额区**垂直居中**于「页眉下沿 → 进度条上沿」这段空间，不写死 y。

## 5. 方案 B：保留标签的折中版

如果想要「窝囊费已赚」这行：

```
│        窝囊费已赚  ·····················             │  11px, 30% 灰
│         0 3 5 8 . 2 9 1 7                          │  金额
```

标签**左对齐到金额左边缘**（不是居中），与金额形成"标题 + 数字"的阅读顺序，且不占额外高度——标签压在金额上方的留白里。

## 6. 三档窗口尺寸

| 尺寸 | 金额上限 | 保留元素 |
|---|---|---|
| 480 × 240 | 120px | 全部 |
| 420 × 220 | 104px | 去掉标签，日期 + 金额 + 条 + 底栏 |
| 360 × 180 | 88px | 只留金额 + 条；底栏折进 tooltip |

## 7. 动效优先级

1. **金额滚动**（最高）——每列独立缓动，180ms；
2. 进度条燃烧点 + 火星；
3. 状态文字切换的淡入淡出；
4. 其余元素不做动画。

## 8. 立即可落地的三条

如果只改三件事，按收益排序：

1. **去掉 `¥` 和「窝囊费已赚」标签** → 金额可用宽度增加约 40px，字号能大 10~15%；
2. **金额改成按宽度自适应（上限 120px）而不是固定 80px** → 金额随额度变化始终撑满；
3. **金额区垂直居中**而不是顶部固定 → 上下留白对称，视觉重量集中。
