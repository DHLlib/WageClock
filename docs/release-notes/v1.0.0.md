## 工资时钟 v1.0.0

把上班时间换算成钱的 Windows 桌面小挂件：实时滚动「窝囊费已赚」，倒数距离下班还有多久，进度条是一根从左往右烧掉的仙女棒。

### 安装

下载 `WageClockSetup-1.0.0.exe` 双击运行：

- **为当前用户安装**，不弹 UAC，不需要管理员权限
- 可以**自选安装目录**（默认 `%LOCALAPPDATA%\Programs\WageClock`）
- 自动检测 **WebView2 运行时**与 **.NET Framework 4.8**：缺失时可以用内置的微软引导程序一键静默安装
- 卸载走「设置 → 应用」，**默认保留**个人设置（月薪、班次、窗口位置）
- 静默安装：`WageClockSetup-1.0.0.exe /silent /dir=D:\Apps\WageClock /nostart`

校验：

```
SHA256  20071CACBF32CDFB005C849B3CECB8A525D2B47E2E5DE3429BC5A0602678D78A
```

### 这一版有什么

- **实时金额**：4 位整数 + 4 位小数，20 帧/秒滚动，小数位字号是整数的 2/3，未用到的数位保持淡灰
- **进度配色**：金额与「距下班」按今日完成度从红线性渐变到绿
- **仙女棒进度条**：已经过的时间烧成灰，未过的是引线，火头每秒喷射约 95 颗带拖尾的火星
- **底栏三格**：距周末、距下班（到百分秒的数字钟）、本月出勤
- **排班**：上午 + 下午两段，午休不计薪；内置 2026 年法定节假日与调休补班
- **托盘与快捷键**：托盘常驻，`Ctrl + Alt + W` 显示/隐藏；关闭行为三选一（跟随自启 / 收进托盘 / 退出）
- **外观**：深色 / 浅色 / 跟随系统，点一下立即生效

### 系统要求

- Windows 10 / 11
- WebView2 运行时（Win11 自带；缺失时安装程序会代为安装）
- .NET Framework 4.8（Win10 1903 之后自带）

### 已知限制

- 单实例运行，重复启动会唤回已有窗口
- 节假日表目前只到 2026 年，跨年后需要更新
- 不要从低完整性级别的目录（例如某些沙箱路径）启动程序，否则托盘图标与开机自启会失效
