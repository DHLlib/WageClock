## 工资时钟 v2.0.0

一次彻底的重写：**去掉 WebView2 与整套 HTML/CSS 前端，界面改由 C# 直接自绘**。

### 为什么要重写

v1.x 的界面是 WebView2 里的网页。这个架构有两个绕不过去的问题：

- **透明做不到**。窗口模式的 WebView2 是一个不透明子窗口，想要"背景半透明、数字不透明"必须先把自己从截图里排除、再抓背后画面做模糊底图，代价是延迟和录屏副作用；合成托管的真透明方案验证可行但没能集成成功（过程记录在 `docs/composition-hosting-notes.md`）。
- **依赖太重**。安装包 2.3 MB，其中 1.85 MB 是 WebView2 运行时引导程序；运行时本身还可能随版本变化出问题。

### 这一版的变化

- **卡片改为分层窗口 + GDI+ 自绘**：`WS_EX_LAYERED` + `UpdateLayeredWindow`，逐像素 alpha，背景可以很透、数字始终不透明，不需要截屏、不需要排除录屏。
- **界面按新设计稿重排**：去掉「窝囊费已赚」标签与 `¥` 符号，金额独占视觉重心；整数 4 位与小数 4 位按 1 : 1.5 双字号、共享基线，字号按宽度与高度自适应。
- **设置窗口改回原生 WinForms**：月薪、班次、工作日、主题、关闭行为、置顶、自启，底部实时预览日薪/时薪，跟随主题换肤。
- **计算核心移植到 C#**：`Schedule.cs` 逐条复刻原 JS 版本的语义，`SelfTest.cs` 保留 54 条断言，`WageClock.exe --selftest` 可跑。
- **不再依赖 WebView2**，安装包从 2.3 MB 降到 **227 KB**，主程序 109 KB。

### 修复

- 关闭按钮现在按「关闭行为」执行：`quit` 退出、`tray` 收进托盘、`auto` 按托盘可用性二选一。
- 隐藏到托盘时不再把图标从托盘移除又加回（那样做会让图标永久消失）。
- 设置窗口重复打开时复用已有窗口，不再弹出第二个。
- 安装程序：选择目录时不再递归扫描（大目录会卡死）、覆盖安装前结束所有运行实例、崩溃时弹出可读错误。

### 升级

可覆盖安装 v1.x，`%APPDATA%\WageClock` 里的个人设置会被沿用。校验值见同页 `SHA256SUMS.txt`。
