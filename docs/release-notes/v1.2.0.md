## 工资时钟 v1.2.0

这一版**移除了背景不透明度**，界面回到干净状态。

### 为什么移除

v1.1.0 加过「背景不透明度」滑块，实现方式是截取窗口背后的画面做模糊底图，有两个绕不过去的缺陷：

- 背景是**定时刷新的快照**，背后窗口变化有约 1 秒延迟；
- 透明状态下组件会**从录屏与截图里消失**（要把自己排除出截图才能拍到背后）。

本来打算用 WebView2 的合成托管（DirectComposition）做真透明，spike 里四项目标过了三项——真透明、CSS 渲染、中文字形都成立，但接进正式程序后合成表面始终不吐 alpha，排查掉了三个嫌疑（DWM 圆角、共用 WebView2 环境、窗体底色），剩下的问题需要成块时间用二分法定位。

综合下来这个功能的**收益不抵复杂度**，整块移除。

### 这一版的变化

- 设置页不再有「背景」滑块，卡片背景恢复成实色渐变；
- 宿主删掉背景取样、截图排除与相关 IPC（净减约 220 行）；
- 备份文件 `%APPDATA%\WageClock\backdrop.png` 与设置里的 `opacity` 键都不再使用，升级后会自动忽略。

### 升级

可覆盖安装 v1.0.x / v1.1.x，`%APPDATA%\WageClock` 里的个人设置不受影响。校验值见同页 `SHA256SUMS.txt`。
