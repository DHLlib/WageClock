## 工资时钟 v2.0.1

修复 v2.0.0 里一个会让卡片跑到屏幕外的定位问题。

### 修复

- **默认位置按窗口实际宽高计算**。v2.0.0 的默认落点仍按旧的 400×272 卡片写死，而 2.0 的卡片是 480 宽，右下角落点会超出屏幕右缘——**关闭按钮落在屏幕外，点不到**，看上去像「× 没反应」。
- **读取保存的窗口坐标时夹回可见区域**。之前用旧尺寸留下的坐标升级后会落在屏幕外；现在启动时会把位置限制在工作区内，并在日志里记一条 `window pos clamped`。

### 验证

在 1920×1080 的屏幕上，全新安装（没有 `settings.json`）后卡片落在 `1416,720`，右边缘 1896 在屏内；点 `×` 正常收进托盘。

### 升级

可覆盖安装 v1.x / v2.0.0。校验值见同页 `SHA256SUMS.txt`。
