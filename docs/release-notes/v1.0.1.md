## 工资时钟 v1.0.1

一个托盘交互的补丁版本。

### 修复

- **右键托盘图标不再打开面板**。之前 `NotifyIcon.Click` 对左右键都会触发，右键会先把窗口切换到显示状态，然后才弹出菜单；现在右键只弹菜单（显示/隐藏、设置、窗口置顶、开机自启、退出），左键才切换显示。

### 与 v1.0.0 的差异

只有这一处代码改动，功能、安装方式、数据位置完全一致。已装 v1.0.0 的可以直接覆盖安装，`%APPDATA%\WageClock` 里的个人设置不受影响。

### 安装

下载 `WageClockSetup-1.0.1.exe` 双击运行：

- 为当前用户安装，不弹 UAC，可选安装目录
- 自动检测 WebView2 运行时与 .NET Framework 4.8，缺失时用内置引导程序安装
- 卸载走「设置 → 应用」，默认保留个人设置
- 静默安装：`WageClockSetup-1.0.1.exe /silent /dir=D:\Apps\WageClock /nostart`

校验值见同页的 `SHA256SUMS.txt`，用 `Get-FileHash` 对照即可。
